# Q1 — 大城北空氣品質監測站（標題顯示）

說明
- 使用 ESP32 + ILI9341（240x320, SPI）在螢幕上顯示中文標題「大城北游泳池空汙偵測」。
- 本範例不包含感測器，僅完成版面與中文顯示。

檔案
- `main.py`：初始化顯示器並呼叫 `draw_title()` 繪製標題。

執行
1. 在對應 task 資料夾啟動 Wokwi 或上傳到開發板。
2. 執行 `main.py`，螢幕上會顯示標題。

說明（顏色規則）
- 本作業以學號末位數選色；此學生學號末位為 `6`，選用 magenta（RGB 255,0,255）。

若需修改
- 想改每列字數請編輯 `per_row` 變數；如需改顏色，修改 `STUDENT_LAST_DIGIT` 或 `COLOR_MAP`。
