# Week 13 Homework - SH1107 + DHT22 中文動畫溫度看板

## 作業說明
本作業以 Week 13 的 task3a 與 task4 為基礎，整合成一個可連續運作的 SH1107 中文動畫溫度看板。畫面主題採用一星龍珠作為主視覺，左側是英文資訊與溫度區塊，右側是直排的「花火節」中文字動畫。整體版面設計目標是讓使用者一眼看出圖形主題、文字區塊、感測資訊與動態效果，不是只顯示單行溫度文字。

## 版面配置
1. 頂部顯示英文資訊：`Penghu University`、`of Science & Tech`、`Dept of CSIE` 與年份 `2026`。
2. 顯示學號識別：`ID:1114405001`（直接顯示在 OLED 畫面）。
3. 中間偏左區域顯示龍珠主視覺（雙圓 + 星形）。
4. 下方左側是溫度框，固定以 `xx.x C` 呈現。
5. 右側為中文直排動畫區（花火節）。

## 動畫設計
中文動畫每 250ms 更新一幀，包含兩種效果：
1. 聚焦放大：三個字輪流放大（`shrink=1`）與縮小（`shrink=2`）。
2. 波浪位移：每個字依 frame 套用上下位移陣列 `(-4, 0, 4, 0)`，形成持續晃動感。

這樣的設計可以讓畫面在 5 秒以上的錄影中清楚觀察到連續動畫，符合作業要求的可驗收性。

## DHT22 整合方式
DHT22 透過 GPIO23 讀值，程式每 2 秒更新一次感測資料。每次讀取會在 Serial Monitor 印出：
- `temperature`
- `humidity`

範例輸出：

```text
[DEBUG] temperature = 24.0C, humidity = 53.0%
```

溫度資料固定顯示在 OLED 的溫度區塊，格式為 `xx.x C`。

## 例外處理與穩定性
讀值流程使用 `try/except` 保護：
1. 成功時更新最新溫濕度。
2. 失敗時不讓程式中止，保留前次有效值。
3. Serial 印出 `[ERROR] DHT22 read failed: ...`。
4. OLED 顯示 `Sensor Error` 區塊提示感測異常。

透過這種設計，即使感測器短暫讀值失敗，動畫與主畫面仍可持續更新，降低卡死風險。

## 遇到的問題與解法
問題：一開始直接用 `framebuf.blit()` 繪製中文字時，縮放與跨區域顯示不穩定，某些字形在動畫放大時容易裁切。

解法：改成逐像素繪製並加入 `wrap_y` 邏輯。當字元超出底部時，y 座標可模數回到上方，避免字型在邊界位置嚴重破圖。同時保留 `center_x`、`center_y` 與動畫參數常數，後續可以依實測畫面快速調校。
