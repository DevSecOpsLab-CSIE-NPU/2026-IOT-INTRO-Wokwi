# Week 13 Homework

本作業把 Week 13 的兩個重點整合成同一個作品：`task3a` 的 SH1107 版面與動畫，結合 `task4` 的 DHT22 即時溫度讀值。畫面採用左右分區的構圖，左側放英文說明與主視覺龍珠，右側放直排中文動畫「花火節」，底部則保留溫度與濕度資訊區，讓畫面不會只剩單行溫度字。

動畫部分不是只閃爍文字，而是同時讓龍珠做脈衝變化、星形中心輕微縮放，並讓中文三個字以不同的 y 位移產生波浪感。這樣在 200 到 300 毫秒的刷新節奏下，畫面會持續有可觀察的動態，符合作業對動畫的要求，也更接近參考圖那種有層次的主視覺。

DHT22 的整合方式是獨立封裝成 `read_sensor_safe()`。程式每兩秒讀一次感測器，讀成功時會在 Serial 印出 `temperature` 與 `humidity`，並更新 OLED 顯示；如果暫時讀取失敗，程式不會中斷，而是印出錯誤訊息、在畫面上顯示 `Sensor Error`，同時保留前一次成功的溫溼度數值，避免畫面整體失真。

我這次遇到的主要問題是 SH1107 的座標與畫面層次容易打架，尤其中文點陣如果直接用預設位置，很容易擠到溫度區或超出可視範圍。解法是先把畫面切成固定區塊，再把中文動畫鎖在右側，底部獨立做溫度面板，並保留 `center_x`、`center_y` 這類校正常數，之後如果換版型，只要調整這些參數就能快速重排。

## 檔案

- `main.py`：SH1107 + DHT22 整合主程式
- `diagram.json`：Wokwi 佈線
- `wokwi.toml`：模擬器設定

## 執行方式

在此資料夾執行：

```bash
make run
```
