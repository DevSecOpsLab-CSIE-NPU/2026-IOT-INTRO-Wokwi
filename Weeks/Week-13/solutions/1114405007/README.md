# Week 13 作業說明：SH1107 中文動畫溫度看板

本作品採三區版面：左側為英文資訊與學號 ID:07，中央是一星龍珠，右側為直排「花火節」動畫，左下角以資訊框顯示 TEMP/HUM。背景加入煙火爆點與星點，保留前景可讀性。

動畫設計使用多軌同步：龍珠脈動放縮，花火節三字輪流放大並做上下波浪與左右微擺，背景煙火分時爆開。主迴圈每 250ms 更新一幀，維持連續且可觀察的效果。

DHT22 每 2 秒讀值一次，成功時在 Serial 輸出 temperature、humidity；失敗時由 try/except 攔截，保留前次有效值並在 OLED 顯示 Sensor Error，確保程式不中斷。

我遇到的問題是「花火節」曾被切半。原因是位移後跨出邊界且啟用 wrap_y。解法為關閉 wrap_y，並對字的 x/y 做範圍夾制，讓 16px 與 32px 字形都能完整顯示。
