# Week 13 Homework: SH1107 + DHT22 中文動畫溫度看板

## 學號
**1114405020**

## 版面配置

本作業以 task3a 的龍珠版型為基礎，結合 task4 的 DHT22 感測整合（`rotate=90`），在 SH1107 OLED (128x128) 上呈現完整的中文動畫溫度看板。

版面分為四個區域：
1. **頂部資訊區**（y=0~12）：左側顯示 "Penghu Univ"、"Dept of CSIE"，右側顯示年份 "2026"。
2. **一星龍珠主視覺**（中心 x=32, y=64）：由雙層圓圈與五角星組成，星星大小依溫度數值動態變化（加分項目）。
3. **中文字動畫區**（x=100, y=50~110）：直排顯示「花火節」三個中文字，以波浪位移搭配循環放大效果。
4. **溫度資訊區**（y=25~50）：顯示 DHT22 即時溫度與濕度，格式為 `xx.x C` 與 `xx.x%`。

## 動畫設計

動畫採用每 250ms 更新一幀的機制，包含以下效果：
- **星星脈動**：龍珠內的星星大小隨即時溫度偏移，溫度越高星星越大。
- **中文字波浪舞**：三個字「花火節」以 4 幀波浪週期 (-5, 0, 5, 0) 上下擺動，依序輪流放大（24x24 vs 16x16 顯示），放大的字向左偏移 4px 保持置中。
- **循環週期**：每 12 幀完成一次完整動畫循環，節奏明確可觀察。

## DHT22 整合方式

- 使用 `dht.DHT22(Pin(23))` 初始化感測器，與 diagram.json 接線一致。
- 每 2 秒讀取一次溫度與濕度，讀取後透過 Serial 輸出 `[DEBUG] temperature/humidity`。
- 讀值失敗時顯示 `Sensor Error` 於 OLED，並保留最後一次有效值，程式不崩潰。
- 採用 `try/except` 包裹感測器讀取，任何例外均被補獲並記錄。

## 問題與解法

**問題**：SH1107 在 Wokwi 中使用 `rotate=0` 時，顯示中心並非理論的 (64, 64)，而是實測約 (64, 90)。

**解法**：參考 task3a 的實測校正，將龍珠中心設為 `(54, 90)`，並保留 `TEXT_Y_OFFSET=36` 讓文字區塊對齊可視區域頂部。所有座標常數均集中於程式開頭，方便後續調整。

## 加分項目

1. **溫度區間視覺化**：星星大小 = `6 + int((temp * 0.2) % 6)`，溫度不同時星星大小會變化。
2. **參數化設定**：`TEMP_INTERVAL_MS`、`ANIM_INTERVAL_MS`、`CENTER_X`、`CENTER_Y` 等常數集中定義於程式前端，易於調整。
