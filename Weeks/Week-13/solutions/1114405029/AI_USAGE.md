## 二、AI 協助但我有自行理解與調整的部分

AI 提供了程式架構與修改建議，但我有依照實際 Wokwi 畫面進行測試與調整，包含：

1. **OLED 方向校正**  
   一開始 OLED 方向與預期不同，因此根據 Wokwi 顯示結果調整 `rotate` 參數。

2. **I2C 腳位確認**  
   依照 `diagram.json` 接線確認：
   - GPIO22 對應 SDA
   - GPIO21 對應 SCL

3. **DHT22 腳位確認**  
   確認 DHT22 DATA 接在 GPIO23。

4. **bitmap 顯示格式修正**  
   一開始使用 `framebuf.MONO_HMSB` 時，悟空圖像顯示成橫條紋。後來依照轉換程式的 byte 排列方式，改成 `framebuf.MONO_VLSB`。

5. **悟空圖片素材重新選擇**  
   一開始使用的圖片轉換後不清楚，後來改用黑白漫畫風、頭部較大、線條較清楚的圖片，再重新轉換成 bitmap。

6. **OLED 版面微調**  
   因為 128x128 畫面空間有限，我有根據畫面實際顯示情況調整：
   - 龍珠位置
   - 悟空位置
   - 花火節位置
   - 溫濕度位置
   - 學號位置
   - 右上角 `2026` 位置
   - 煙火特效位置

7. **主視覺位置交換**  
   一開始龍珠與悟空的位置與參考圖差很多，因此後來重新調整：
   - 龍珠改到中央偏左
   - 花火節改到右側
   - 悟空保持在中央主視覺區

   讓畫面整體更接近參考版型。

8. **避免圖形超出畫面**  
   當龍珠或中文字太靠邊時，畫面可能被切掉或出現左右分裂，因此我有反覆調整座標，避免超出 OLED 邊界。

9. **保留必要功能**  
   在修改動畫與畫面配置時，我有保留：
   - DHT22 感測
   - Serial debug
   - 錯誤處理
   - 學號顯示
   - 中文顯示

10. **花火節放大動畫調整**  
   一開始「花火節」切換速度太慢，因此後來重新調整時間控制，讓：
   - 花 放大約 2 秒
   - 火 放大約 2 秒
   - 節 放大約 2 秒

   動畫效果更明顯。

## 三、AI 建議後採用的技術

### 1. 參數化設定

我採用 AI 建議，將動畫速度、感測器讀取間隔與輪播間隔設定成常數：

```python
ANIMATION_DELAY_MS = 120
SENSOR_INTERVAL_MS = 2000
SWITCH_INTERVAL_MS = 2000
```

這樣可以讓程式更容易調整，也符合加分項中的參數化設定。

### 2. DHT22 安全讀取

我採用 AI 建議，將 DHT22 讀值包成函式：

```python
def read_sensor_safe():
```

並使用 `try/except`：

```python
try:
    dht_sensor.measure()
    temperature = dht_sensor.temperature()
    humidity = dht_sensor.humidity()
except Exception as e:
    sensor_ok = False
```

這樣可以避免感測器暫時讀值失敗時，整個程式直接停止。

### 3. Serial Debug

AI 建議每次成功讀取感測器後印出 debug 訊息，例如：

```text
[DEBUG] temperature = 24.0C, humidity = 40.0%
```

我有採用這個格式，方便助教確認 DHT22 真的有在讀取即時資料。

### 4. 悟空 bitmap 顯示

AI 協助我使用：

```python
import framebuf
```

並透過：

```python
goku_fb = framebuf.FrameBuffer(
    goku_bitmap,
    goku_width,
    goku_height,
    framebuf.MONO_VLSB
)
```

建立 bitmap 顯示物件，再使用：

```python
display.blit(goku_fb, x, y)
```

將悟空圖片顯示到 OLED 上。

### 5. 2 秒輪播模式

AI 建議使用時間差計算目前模式：

```python
elapsed = time.ticks_diff(now, start_time)
mode = (elapsed // SWITCH_INTERVAL_MS) % 2
```

我採用後讓畫面每 2 秒在以下兩種模式切換：

- 龍珠模式
- 悟空模式

這樣可以讓畫面更有動畫感，也避免所有元素同時擠在一起。

### 6. 中文點陣顯示

由於 MicroPython 內建字型不支援中文字，AI 協助我使用中文字點陣資料，將「花」、「火」、「節」用 `bytearray` 儲存，再透過 pixel 繪製到 OLED 上。

雖然程式內部 key 使用：

```python
"HUA"
"HUO"
"JIE"
```

但實際畫面顯示的是中文「花火節」。

### 7. 避免十字線與輔助線

我一開始不希望 OLED 畫面出現十字線、座標線或 debug line。AI 協助我檢查並避免使用不必要的輔助線，例如：

```text
hline()
vline()
center guide
crosshair
debug line
```

最後畫面中保留的是正式圖形與動畫，不再出現穿過人物或龍珠的輔助線。

### 8. 溫度區間視覺化

AI 建議依照 DHT22 溫度區間調整龍珠星星大小，例如：

```python
if temperature >= 28:
    temp_level = 3
elif temperature >= 24:
    temp_level = 1
else:
    temp_level = -1
```

再將 `temp_level` 加入星星大小，讓溫度不只用文字顯示，也會影響視覺效果。這項功能對應到作業加分項。

### 9. 花火節依序放大動畫

AI 協助我設計「花火節」三個中文字依序放大的效果，讓畫面中的中文區塊不只是靜態顯示。

概念如下：

```text
花 放大約 2 秒
火 放大約 2 秒
節 放大約 2 秒
然後循環
```

這讓中文動畫更明顯，也符合題目要求的「中文字動態區塊」。

### 10. 參考圖版型重構

後期我有依照參考圖重新調整整體版面，包括：

- 將畫面資訊往左移
- 右上角加入 `2026`
- 龍珠改到中央偏左
- 花火節移到右側
- 調整悟空與龍珠輪播位置
- 調整煙火位置避免碰到溫度

讓畫面更接近作業提供的參考版型邏輯。

## 五、遇到的問題與 AI 協助解法

### 問題 1：Wokwi 找不到 goku_bitmap.py

一開始 `main.py` 使用：

```python
from goku_bitmap import goku_bitmap, goku_width, goku_height
```

但 Wokwi 執行時出現：

```text
ImportError: no module named 'goku_bitmap'
```

後來透過 `make.bat` 與 Wokwi 的執行流程，讓 bitmap 資料能與主程式一起正確載入執行，解決了 MicroPython 找不到外部檔案的問題。

### 問題 2：合併檔案時中文字亂碼

PowerShell 合併檔案時，中文字串可能變成亂碼，造成 Python 語法錯誤。因此後來將中文字 key 改成英文 key，例如：

```python
"HUA"
"HUO"
"JIE"
```

但 OLED 顯示仍然透過點陣資料畫出中文。

### 問題 3：悟空 bitmap 變成橫條紋

原本使用：

```python
framebuf.MONO_HMSB
```

但畫面顯示橫條紋。後來發現轉換程式是以垂直 8 pixels 為一組，因此改成：

```python
framebuf.MONO_VLSB
```

圖像才正確顯示。

### 問題 4：龍珠左右分裂

當龍珠圓心太靠右時，圓形超出 128x128 OLED 範圍，導致畫面左邊出現另一半圖形。後來調整圓心座標，確保圖案不超出邊界。

### 問題 5：畫面元素互相遮擋

由於 OLED 解析度只有 128x128，若同時顯示悟空、龍珠、花火節、煙火、溫濕度，畫面會太擁擠。後來採用 2 秒輪播，使龍珠與悟空分開呈現，讓畫面更清楚。

### 問題 6：花火節位置被切到

一開始將「花火節」移到右側時，因為座標太靠邊，導致中文字被 OLED 邊界切掉。後來多次調整 x 座標，讓三個字可以完整顯示在右側。

### 問題 7：年份 2026 顯示不完整

一開始右上角 `2026` 會被切成一部分顯示在左邊、一部分顯示在右邊。後來調整文字座標，讓年份可以完整顯示在右上角。

### 問題 8：煙火特效干擾溫度顯示

一開始煙火尾巴太長，會碰到下方溫度區塊。後來縮短煙火尾巴，避免影響 `24.0 C` 與 `H:40%` 的可讀性。

### 問題 9：花火節放大速度不自然

一開始「花」放大太久，導致「火」與「節」很晚才切換。後來重新調整動畫切換時間，讓三個字能固定每 2 秒依序放大。

### 問題 10：參考圖版型差異太大

最初版本中：
- 龍珠在右邊
- 花火節在左邊
- 畫面整體與參考圖差異較大

後來重新調整：
- 龍珠改到中央偏左
- 花火節改到右側
- 上方英文資訊往左移
- 右上補上 `2026`

讓畫面版型更接近題目提供的參考圖。
