# Week 13 Homework - SH1107 + DHT22 中文動畫溫度看板

## 作業說明

本作業以 Week 13 的 task3a 與 task4 為基礎，整合出一個可持續運作的 SH1107 OLED 中文動畫溫度看板。版面採用「英文資訊區 + 龍珠主視覺 + 中文動態區 + 即時溫度區」的結構，讓畫面具備清楚層次，不會只剩單行溫度資訊。主視覺使用雙圓與星形，對應龍珠風格。

## 動畫設計

動畫每 250ms 更新一次，以「花火節」三字輪流放大，未放大的字維持縮小版，同時搭配波浪位移，形成可觀察的循環動態。星形大小會依溫度區間改變，增加溫度資訊的視覺連動效果。整體動畫可連續運行，不會因感測讀值失敗而中止。

## DHT22 整合

程式每 2 秒讀取一次 DHT22，顯示格式固定為 xx.x C，並同步顯示濕度 RH。每次讀值後會在 Serial Monitor 印出 temperature 與 humidity 的 debug 訊息，便於驗收與除錯。OLED 畫面也加入學號識別：ID:1114405056。

## 錯誤處理

感測讀值採用 try/except，若發生暫時性錯誤，程式不會崩潰；Serial 會顯示錯誤訊息，OLED 顯示 Sensor Err，並保留前次有效溫濕度數值，符合作業要求的穩定性與容錯機制。

## 檔案

- main.py: 主程式（動畫、中文、溫濕度、學號、錯誤處理）
- diagram.json: Wokwi 元件與接線設定（SH1107 + DHT22）
- wokwi.toml: 韌體路徑設定
